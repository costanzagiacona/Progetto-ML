# Pneumonia classification
Descrizione:
• Sviluppo di un modello di Deep Learning per la classificazione automatica binaria di radiografie toraciche (Polmonite vs Normale).
• Progettazione e implementazione di una Rete Neurale Convoluzionale (CNN) per l'estrazione automatica delle feature dalle immagini mediche.
• Gestione del dataset tramite tecniche di Preprocessing (ridimensionamento, normalizzazione) e Data Augmentation (rotazione, zoom, flip) per mitigare l'overfitting e migliorare la generalizzazione del modello.
• Valutazione delle performance tramite analisi delle curve di apprendimento (Loss/Accuracy), Matrice di Confusione e metriche di classificazione (Precision, Recall, F1-Score).
